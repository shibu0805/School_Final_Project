# 地圖與語音顧問重構

更新日期：2026-11-07。

## 使用流程

主要導覽只保留「全台空品地圖」「AI 語音顧問」。首頁不要求使用者填表。縣市卡片僅有一個主要操作「問問 AI 顧問」，會帶入所選縣市。也能直接進入顧問，以自然語言指定縣市與活動；缺少地點時只追問地點。

原有介面保留為 src/ResearchApp.tsx，由頁尾「開發者／研究模式」延遲載入。既有官方 API、知識庫、八個工具、Gemini／Ollama adapter、30 題情境入口與 SQLite 紀錄繼續可用。

## 真實行政區地圖

- public/geo/taiwan-counties.geojson：國土測繪中心圖資轉製，22 個縣市 Feature，EPSG:4326；版本、來源、授權及 SHA256 見同目錄 SOURCE.md。
- shared/geometry.mjs：從 GeoJSON Polygon／MultiPolygon 直接生成 SVG 路徑，保留外環與孔洞，畫面投影只移除亞像素重複點。
- 本島、澎湖、金門含烏坵、連江、東北離島、東沙、南沙分圖呈現。離島的位置與比例為版面配置，非實際相對位置。
- 支援滑鼠 Hover、點擊、鍵盤 Enter／Space、手機觸控及縣市選單；小面積縣市可改由選單選擇。提供本島縮放與圖例。
- 地圖與主介面不依賴遠端底圖服務，GeoJSON 為隨程式部署的靜態檔。

## 縣市代表 AQI

本系統名稱固定為 **縣市測站最高 AQI**，非縣市每個地方的真實 AQI，也不是環境部發布的單一縣市指標。

1. 按縣市正規化「台／臺」，同站號重複資料保留最新發布的紀錄。
2. 有效 AQI 必須為整數且介於 0–500。缺值、非數字、負值、超出範圍與無法解讀時間者排除。
3. 正式資料以 Asia/Taipei 解讀發布時間，超過兩小時或超前系統時間五分鐘者排除。這是專題自訂工程品質門檻，非官方健康標準。
4. 每個縣市只納入最新有效發布小時的測站，不混合不同小時的數據。同小時不同分鐘則保留最早／最晚發布範圍。
5. 對同批次有效站取最高 AQI；並列時取較新發布紀錄，再以站號穩定排序。指標污染物來自代表測站的官方 pollutant 欄位，沒有就保持缺值，不推測。
6. 沒有有效站則 aqi=null，灰色 #c3ccd1，「暫無資料」。排除原因、納入數與總數都可在卡片展開。
7. 顧問預設採用同一個聚合結果；自然語言明確指定測站時，才標示為指定測站觀測。不同來源或 demo／live 不混用。

AQI 色碼：0–50 #00e400；51–100 #ffff00；101–150 #ff7e00；151–200 #ff0000；201–300 #8f3f97；301–500 #7e0023。依環境部官方色碼，地圖不以品牌淡色取代。

新增 GET /api/counties?mode=live|demo，回傳 22 縣市、代表站、有效數、完整站表、quality、時間範圍、統計依據及生成時間。實際發布時間與查詢時間分開顯示。

## 簡潔回答與後端判定

response 新增 summary、assessment、actions、details。主要畫面只顯示「目前狀況／AI 評估／建議做法」，最多三項建議；詳細分析預設收合，展開才載入趨勢模組。

assessment 只能由 server/guidelines.mjs 的 assessActivity 產生，不能由 LLM 覆寫：

| 條件（有效目前觀測） | 狀態 |
| --- | --- |
| AQI ≤ 100，且未觸發下列敏感族群條件 | 適合 |
| AQI 51–100 的敏感族群，或 AQI > 100 且未達避免規則 | 建議調整 |
| AQI > 200；或 AQI > 150 且敏感／高負荷；或 AQI > 100 且敏感並高負荷 | 不建議目前進行 |
| 無有效／同批次／未過期資料，或指定未來時段卻無可靠預報 | 資料不足，無法可靠評估 |

高負荷為高強度或時長至少 60 分鐘，是本專題保守活動調整規則，**不是官方新增門檻或醫療風險公式**。官方活動建議作為依據，應清楚區分本系統操作分類與官方原文。

未提供族群時暫依一般民眾，活動強度依類型推定、時長暫以 30 分鐘；假設列於詳細分析，可直接用自然語言更新，並非要求填滿表單或宣稱安全時限。「今天」僅能參考目前觀測；「明天／指定早晚」缺少可信空品預報時不回覆適合。

API 失敗仍回傳保留 Profile 的 insufficient 結果，以便後續追問。模型不可用時保持原本透明降級與 trace。對話上下文是結構化 Profile，不會自動把完整聊天歷史交給模型。

## Web Speech 能力與隱私

- 優先偵測 window.SpeechRecognition 或 webkitSpeechRecognition；lang=zh-TW，單次辨識、支援暫時文字。
- 只有使用者點擊麥克風才開始；不在載入頁面時要求麥克風或持續錄音。
- 最終辨識文字會先顯示於畫面，送至原 /api/chat；防止同一次辨識重複送出。
- onstart／onend／onerror 控制聆聽動畫；等待 API 與朗讀各有獨立狀態，動畫不假裝正在錄音。
- 不支援、不安全環境、拒絕權限、裝置不存在、無語音、語言不支援、網路失敗皆有文字提示與打字替代。
- SpeechSynthesis 為使用者點「朗讀回答」後才播放；優先 zh-TW、其次其他中文語音。無中文聲音或尚未載入時顯示提示，不默默使用不合適的預設聲音。
- 切換頁面會停止辨識、取消本次回應請求及本專題正在播放的語音。
- 辨識可能使用瀏覽器供應商雲端服務，已在輸入框下揭露；本機後端不接收／保存音訊，只接收文字。若選 Gemini，問題與條件會送給 Google，設定頁另有說明。
- 沒有宣稱所有瀏覽器支援相同；Chrome／Edge 等的實際辨識能力仍受平台、網路、權限、政策影響。不要用 file:// 開啟，請用 localhost 或 HTTPS。

參考：[SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)、[SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)。
