## 研究題庫

前端產生 30 題，輪替臺中／臺北／高雄／花蓮／臺南、五族群、六活動與正常／缺值／API 失敗／過期／無預報／臭氧主導六種條件。

完整研究需將 AQI 50、100、150、200、300 等邊界、活動強度低中高、時長 15／30／60 分鐘加入固定快照。畫面上的題庫是實驗入口，並非已完成自動實驗 runner。點擊載入不會自動注入故障，故障透過測試 mock 驗證。

## 比較系統

1. Baseline A：僅使用 AQI 等級及官方準則。可呼叫 get_health_guidelines 建立輸出；未建立完整批次 runner。
2. Baseline B：一般 LLM，不附即時工具；尚未實作並執行批次實驗。
3. Proposed Gemini Agent：使用本工具管線；待有效金鑰與模型版本凍結。
4. Proposed Ollama Agent：相同工具與快照，切換本地模型；待安裝與資源量測。

規則工具模式不等同 Baseline A，因為它包含個人化、資料品質與驗證步驟。

## 指標與人工評分

| 指標 | 定義 |
| --- | --- |
| 官方準則一致率 | 符合族群及 AQI 準則的可評案例 ÷ 全部可評案例 |
| 數據正確率 | 有證據且與快照值、單位、時間相符的數字主張 ÷ 所有數字主張 |
| 幻覺率 | 無證據／捏造／把歷史說成未來或即時的主張 ÷ 全部可驗證事實主張 |
| 平均回應時間 | 固定環境下完整端到端耗時總和 ÷ 成功回覆次數；失敗與逾時另外報告 |

人工評分逐項標註符合／不符合／不適用；兩位評分者分開審查，分歧保留原始評語並討論裁決。樣本量小時應附分子／分母，不只列百分比。無分母標為不可計算，不填零。

實驗紀錄應包含 case_id、原始問題、Profile、快照識別碼、模型與版本、回答、工具 trace、準則版本、預期依據、驗證結果、延遲、評分者與逐項評分。現有 run export 已保存大部分執行證據，完整評分 schema 與 runner 尚待擴充。

## 人工 UI 驗收

- 桌面與手機寬度：導覽、六污染物卡片、圖表、設定表單、聊天輸入均可使用。
- 官方未連線：顯示明確訊息、數值為缺值，不沿用展示數字。
- 切換模式：清除對話與資料，防止混用；切換縣市共用族群／活動。
- 輸入問題：可追問；工具明細與 JSON 下載符合實際執行。
- 地圖：外部地圖失敗時仍可查看測站資訊；定位拒絕時有提示。
- 實驗頁：所有未評估分數保持空白；展示紀錄標記模擬。
